# HealthQueue – Emergency Routing System

## 🔹 Project Overview
HealthQueue is an AI-assisted emergency routing system that helps patients find the most suitable hospital based on distance, queue length, wait time, and specialization.

## 🔹 Features
- Emergency type selection
- Smart hospital recommendations
- Queue-aware routing
- Clean and responsive UI
